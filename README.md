# Timo Vromen — Developer Portfolio

My personal portfolio website, featuring my experience, technical skills, selected client work and personal projects.

[View the live website](https://www.timovromen.nl/)

## Built with

- PHP partials
- HTML
- CSS
- JavaScript
- Bootstrap

## Run locally

From the project directory, start PHP's built-in development server:

```bash
php -S localhost:8000
```

Then open [localhost:8000](http://localhost:8000) in your browser.
